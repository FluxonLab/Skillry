# Historical Launch Notes - June 2026

These notes preserve the original public-launch messaging for future maintainers. They are not an
active publishing schedule and should be re-verified before reuse.

## Core message

Skillry is an MIT-licensed library of installable, permission-bounded agent skills and subagents
for Claude Code, Codex, Copilot, and Gemini. It emphasizes real files rather than link lists,
least-privilege agent tools, CI validation, generated platform instructions, and full attribution
for third-party content.

## Installation examples

```bash
npx github:FluxonLab/Skillry install --apply --targets claude
npm install -g skillry
```

Claude Code marketplace:

```text
/plugin marketplace add FluxonLab/Skillry
```
