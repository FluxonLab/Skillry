# Skillry Project Pack

This directory is the portable project memory for maintainers and future coding-agent sessions.
It separates verified current state from research recommendations and unapproved future work.

## Read in this order

1. [DECISIONS.md](DECISIONS.md) - canonical scope and decision register.
2. [HANDOFF.md](HANDOFF.md) - current repository, package, CI, branch, and resume state.
3. [WORKING-METHOD.md](WORKING-METHOD.md) - the proposed evidence-first development system.
4. [RESEARCH.md](RESEARCH.md) - research findings and primary-source links.
5. [ROADMAP.md](ROADMAP.md) - prioritized future development, without implementation approval.
6. [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md) - decisions required before an implementation plan.
7. [archive/](archive/) - historical launch and foundation notes retained for context.

## Status vocabulary

- **Target scope:** the approved product direction.
- **Current implementation:** code and documentation present on the default branch.
- **Candidate:** work on a branch or in research that is not merged or activated.
- **Live:** published npm/GitHub state verified against the external service.
- **Research recommendation:** an investigated option, not an implementation decision.

Do not infer that a roadmap item is approved merely because it is documented here.
