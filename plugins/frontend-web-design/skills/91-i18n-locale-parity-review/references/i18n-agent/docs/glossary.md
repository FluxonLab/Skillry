# Glossary

| Term | Meaning |
|------|---------|
| **BCP47** | Language tag standard (`en`, `fr-CA`, `zh-Hans`). Used in `html[lang]` and hreflang. |
| **hreflang** | `link rel="alternate" hreflang="..."` announcing language/region variants. |
| **x-default** | Special hreflang value for the default/fallback experience. |
| **Locale registry** | Single JSON inventory of locales, prefixes, BCP47, dir, priorities. |
| **Calque** | Word-for-word borrow of English structure into another language; usually poor UX/SEO. |
| **Transcreation** | Rewriting marketing copy for equivalent effect in the target culture. |
| **Adaptation (SEO)** | Choosing local query phrasing rather than translating EN keywords. |
| **Market priority** | Tiered investment: primary / secondary / maintain. |
| **Parity** | Same routes/claims available across locales, or honest omission from alternates. |
| **Self-canonical** | Canonical URL pointing at the page’s own locale URL. |
| **Money page** | High-intent commercial/conversion URL (pricing, services, booking). |
| **Utility page** | Low-SEO-value pages (login, cart steps, internal tools)—often noindex. |
| **Translation memory (TM)** | Store of approved source↔target segment pairs for reuse. |
| **T/V formality** | Tu/vous (or equivalent) address formality. |
| **Logical CSS** | Properties like `margin-inline-start` that flip correctly in RTL. |
| **page_locale** | Analytics dimension recording the active locale for a hit. |
